# Changelog

## 1.0.0
- Read-only inventory collection with R12-style pagination and strict coverage checks.
- Inventory, stale discovery, missing data, duplicate candidates and optional software policy audit.
- Offline JSON mode, CSV reports, diagnostic log and optional raw inventory.
- Secure password prompt, TLS verification, retry/backoff and one session renewal.
- GitHub CI and manual TestPyPI/PyPI publishing workflows.
- Live validation against a real NetBrain domain is required before production rollout.
